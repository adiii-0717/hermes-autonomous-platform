# Creative Design & UI/UX Research Guidelines

When designing or substantial redesigning a web application interface, follow this creative research workflow before writing frontend code.

## 1. Product & Audience Identity Analysis
- Identify the target user persona (e.g. Developer, Executive, Creative Professional, Consumer).
- Define the brand personality (e.g. *Authoritative & Editorial*, *Playful & Expressive*, *Cyber & Industrial*, *Ultra-Minimal & Swiss*).

## 2. Visual Design Archetypes (Explore & Invent)
Brainstorm 3 distinct visual directions internally and select the one that best serves the product's identity:
1. **Editorial Minimalist**: Serif headings, high whitespace, rich monochrome with singular accent, high-contrast typography scale.
2. **Neo-Brutalism**: Thick 2px-3px solid borders, vibrant flat colors, hard box-shadows (), bold sans-serif typography.
3. **Swiss Typographic**: Grid-locked layouts, oversized sans-serif typography (Helvetica/Inter/Space Grotesk), asymmetric placement, high contrast.
4. **Luxury Premium**: Deep charcoal/navy backgrounds, gold/emerald subtle accents, elegant thin line borders (), smooth glass elements.
5. **Playful Expressive**: Soft pastel palettes, rounded organic shapes, bouncy micro-interactions, friendly typography (Outfit/Plus Jakarta Sans).
6. **Futuristic / Cyber Technical**: Monospace accents, dark slate background, glowing neon highlights, technical metric grids.
7. **Immersive 3D / Kinetic**: WebGL particle backgrounds, interactive 3D hero objects, physics-based motion.

## 3. Anti-Trope Checklist (STRICTLY BANNED UNLESS JUSTIFIED)
- ❌ **DO NOT** default to purple-and-blue gradients for every project.
- ❌ **DO NOT** use generic floating glow orbs in every background.
- ❌ **DO NOT** create identical 3-card hero sections for every landing page.
- ❌ **DO NOT** use unstyled browser default fonts or unproportional typography sizes.
- ❌ **DO NOT** add decorative animations that slow down user interaction or lack purpose.

## 4. Design System Token Specifications
Every project must specify:
- **Color Ratio (60-30-10)**: 60% Dominant background, 30% Structural surface/cards, 10% Vibrant accent.
- **Typography Scale**:  (32px-56px),  (24px-36px),  (18px-24px), body (14px-16px), caption (12px).
