# Immersive UI Composition Guidelines

## 1. Spatial Layout & Depth
- Layer foreground, midground, and background elements with distinct z-index tiers (`z-10`, `z-20`, `z-30`).
- Use subtle backdrop-filter blurs (`backdrop-filter: blur(12px)`) and semi-transparent borders.

## 2. Editorial Typography Scaling
- Pair bold display headers (`font-size: clamp(2.5rem, 6vw, 5rem)`) with high-contrast body text.
- Maintain intentional, generous negative space to establish strong focal points.
